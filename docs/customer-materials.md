# Материалы заказчика

Архив `voice_router_dataset.zip` проверен 23.09.2026. Все **11 рабочих файлов** побайтово совпадают с `data/case_2/voice_router_dataset/` в репозитории. Два `.DS_Store` — служебные метаданные macOS, в работе не используются. Повторно копировать датасет не требуется.

| Файл | Как используется |
| --- | --- |
| `README.md` | Архитектура, контракт LLM, языковая политика и оценка |
| `README.ru.md` | Развёрнутые требования и правила диалога на русском |
| `README.kz.md` | Казахская версия требований и терминология |
| `scenarios.json` | 40 бизнес-сценариев, 3 системных намерения, границы, примеры, ответы RU/KK; входят в LLM-контекст |
| `slots.json` | 43 слота: типы, enum-коды и готовые вопросы RU/KK; вопросы задаются по одному |
| `actions.json` | 31 мок-действие, очереди, ошибки, требования к подтверждению |
| `knowledge_base.json` | Единственный источник продуктовых фактов; результаты переводятся на язык ответа |
| `mock_backend.json` | Синтетические клиенты, полисы, заявления, платежи; действия выполняются над копией данных сессии |
| `dialogs_sample.json` | 10 примеров диалога; D04/D10 используются для проверки смешанной речи и смены языка |
| `dev_utterances.json` | 104 размеченные реплики: 52 RU, 45 KK, 7 mixed; контроль качества, не таблица ответов для runtime |
| `evaluate.py` | Официальный расчёт primary accuracy, full match и multi-intent recall |

Проверена согласованность всех ссылок сценариев на слоты и действия; пропусков нет. У всех 43 слотов есть вопросы на обоих языках.

Дополнительные требования, применённые после сверки: отвечать на преобладающем языке mixed-реплики, сохранять язык на нейтральных идентификаторах и задавать один вопрос за раз. Дата среза данных — `2026-10-01`.

Полное ТЗ, переданное Дарией в контексте задачи, требует голосового веб-взаимодействия. Оно имеет приоритет над более мягкими формулировками краткого README о голосе/задержке.
